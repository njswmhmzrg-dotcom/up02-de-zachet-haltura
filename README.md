# ЭлектроМир — Каталог электроники

## Описание
Приложение для управления каталогом электроники и заказами. Реализовано на Python с использованием Tkinter и SQLite. Позволяет просматривать товары, оформлять заказы, управлять составом заказов в зависимости от роли пользователя.

## Используемые технологии
- Python 3
- Tkinter
- SQLite
- Pillow

## Функции
- Просмотр каталога товаров с изображениями и характеристиками
- Расчёт скидки 25% для товаров без заказов в прошлом месяце
- Подсветка карточек с количеством ≤ 3
- Оформление заказа с уменьшением остатков
- Список заказов (для Менеджера/Администратора)
- Состав заказа с итоговой суммой
- Удаление заказа с восстановлением остатков
- Редактирование даты (для Администратора)
- Разграничение прав: Клиент, Менеджер, Администратор
